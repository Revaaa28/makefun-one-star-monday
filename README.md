Entry for make.fun's **"One Star for Monday"**. The program writes a single original one-liner (18 words) — a one-star review of Monday as if it were a restaurant — to `/output/entry.txt`:

> One star. Monday came out cold and undercooked, and the bill runs till Friday. The waiter just shrugged.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To write it elsewhere (e.g. for local validation), set `MAKEFUN_OUTPUT`:

```sh
MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py
```
